# IS-recurrence-prediction-tools

## About This Project
Welcome to the **IS-recurrence-prediction-tools** repository. This project provides an open-source data analysis pipeline specifically designed for clinical research on Ischemic Stroke (IS) recurrence.

This repository is part of a larger clinical study investigating the mechanism of the SIRT1/PGC-1α signaling axis and mitochondrial energy metabolism reprogramming mediated by "Tongdu Tiaoshen" acupuncture.

## Features
1. **Data Cleaning (`1_Data_Cleaning.R`)**: Scripts for processing non-targeted metabolomics data (UPLC-Q-TOF/MS), including missing value imputation and normalization.
2. **Statistical Analysis (`2_Statistical_Analysis.R`)**: Multivariate statistical models, including Principal Component Analysis (PCA) and Orthogonal Partial Least Squares Discriminant Analysis (OPLS-DA).
3. **Correlation Analysis**: Pearson/Spearman correlation models linking molecular expression (PBMCs), differential metabolites, and clinical scores (NIHSS, mRS).

## Ultimate Goal
Ultimately, these scripts serve as the data analysis foundation for establishing the **Standard Operating Procedure (SOP)** of acupuncture in preventing ischemic stroke recurrence.
